# יועצת+ | סביבת העבודה החכמה ליועצת החינוכית

קונספט ופיתוח מוצר: מרים רצקר — מפתחת אפליקציות פסיכו־חינוכיות

אפליקציית Web מלאה (Frontend + Backend + Database) ליועצות חינוכיות בבתי ספר ובתיכונים.
שלב 1: ליבת האפליקציה — Database, Authentication, הרשאות מבוססות-שרת, Multi-Tenant, CRUD ו-Workflows בסיסיים.

## טכנולוגיות

- **Frontend:** React 18 + Vite, RTL מלא, בעברית.
- **Backend:** Node.js + Express, REST API.
- **Database:** SQLite (קובץ מקומי, נשמר בין הפעלות) דרך better-sqlite3.
- **Authentication:** JWT ב-cookie httpOnly + bcrypt לסיסמאות.
- **Authorization:** נבדקת בשרת (middleware) לכל בקשה — לא רק ב-UI.

## הרצה מקומית

```bash
npm install
npm run dev
```

- השרת (API) עולה על `http://localhost:4000`
- הלקוח (React) עולה על `http://localhost:5173` (Vite מנתב `/api` לשרת)

בהרצה ראשונה (כשה-Database ריק) המערכת יוצרת אוטומטית בית ספר דמו ומשתמשות דמו.

## מבנה הרשאות

ההרשאות נאכפות בשרת (server/middleware) ולא רק בממשק:

- **יועצת** — גישה מלאה לתוכן הייעוצי (תיקים, פגישות, תצפיות, תוכניות התערבות), כולל מידע חסוי.
- **מחנכת** — גישה רק לתלמידות הכיתה שלה, ללא מידע חסוי, יכולה לפתוח פנייה ליועצת ופגישת מחנכת בלבד.
- **מנהלת** — גישה מערכתית (כל הכיתות/תלמידות), אך ללא הערות והתכנים שסומנו חסויים ע"י היועצת.
- **Admin** — ניהול טכני (משתמשות, יומן פעילות) בלבד, חסום באופן מוחלט מתוכן ייעוצי רגיש.

כל הנתונים מסוננים לפי `school_id` (Multi-Tenant) — אין זליגת מידע בין בתי ספר.
