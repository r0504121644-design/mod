# לב המעבר — Lev HaMa'avor

הבית הדיגיטלי למטפלים המשפחתיים של הורים מבוגרים.
פרוטוטייפ מלא ורספונסיבי, בעברית ו-RTL, בפיתוח **בינה מעברית™**.

> בכל מצב שמשתנה, יש מי שמלווה.

## טכנולוגיה

- Next.js 14 (App Router) + TypeScript
- Tailwind CSS (פלטת מותג מותאמת אישית)
- Zustand (ניהול state עם שמירה מקומית ב-localStorage)
- Recharts לגרפי מגמות
- Lucide-react לאייקונים

## הרצה מקומית

```bash
npm install
npm run dev
```

פתחו http://localhost:3000 — תועברו למסך הכניסה (`/welcome`), ולאחר מכן להקמת מרחב משפחתי (`/onboarding`).

## מבנה עיקרי

```
app/
  (auth)/welcome        מסך כניסה עם OTP
  (auth)/onboarding     הקמת מרחב משפחתי
  (app)/                מעטפת האפליקציה (ניווט, פוטר, סוכן)
    page.tsx            דאשבורד ראשי
    shifts/              תורנויות חכמות
    medications/          תרופות ומלאי
    vitals/                מדדים ומגמות
    appointments/           תורים ואשפוזים
    documents/               מסמכים, אנשי מקצוע ועדכונים
components/
  shell/                רכיבי מעטפת (ניווט, כותרת, פוטר, כפתור סוכן)
  agent/                מגירת "לב המעבר" ומודאל המנוי
  ui/                   רכיבי UI משותפים
lib/
  store.ts              Zustand store מרכזי + נתוני seed
  seedData.ts            נתוני דמו: משפחת לוי
  sanitize.ts             שומר פרטיות (חסימת מספרי ת.ז)
  agentService.ts          גשר לסוכן ה-AI (עם נפילה למענה מדומה)
```

## פרטיות

המערכת חוסמת קלט של רצפי 9 ספרות ומעלה (מספרי זהות) בכל שדה טקסט חופשי, ומבקשת שימוש בכינויים בלבד (למשל "אמא", "דנה") ללא שמות משפחה.
